# VIBE EFFECTS

Vibe Effects 是一个互动视频创作实验室。用户可以打开摄像头，用手势、鼠标或触摸与实时视觉效果互动，并把最终画面录制、预览和保存为视频。

## Beta v0.1

当前提供三个正式玩法：

- 透明幕布：抓住、拉动和掀开虚拟幕布
- 泡泡宇宙：触碰、戳破并用手掌挥开泡泡
- 空间裂缝：用双手撕开现实，露出上传的另一个世界

## 当前功能

- 首页与玩法探索页
- 透明幕布互动玩法
- 泡泡宇宙与空间裂缝互动玩法
- 前后摄像头切换与镜像处理
- MediaPipe 双手识别与捏合抓取
- 鼠标和触摸拖动
- 上传图片或视频作为幕布后的素材
- Canvas 最终画面录制、作品预览
- 优先原生 MP4，必要时在浏览器本地转换为 MP4
- 摄像头、手势、录制、动画和 Object URL 的退出清理

## 本地运行

需要安装 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

终端会显示本地访问地址，通常为 `http://localhost:5173`。

摄像头只能在 `localhost` 或 HTTPS 环境使用。首次进入透明幕布时，需要允许浏览器摄像头权限。

## 生产构建

```bash
npm run build
```

构建结果位于 `dist` 目录。

## 推荐浏览器

- 桌面端：最新版 Chrome、Edge
- Android：最新版 Chrome
- Safari 和 iPhone：可以访问基础页面，但摄像头、MediaRecorder、MP4 编码与 WASM 转换能力因系统版本而异，需要进一步实机验证

## 已知限制

- 单次录制最长 30 秒，暂不录制麦克风或系统声音
- MediaPipe 和 FFmpeg WASM 首次使用需要加载外部运行文件，网络较慢时等待时间会增加
- 不支持原生 MP4 时，保存前需要在设备本地转码；低性能手机可能耗时较长或内存不足
- 某些设备只有一个摄像头，无法切换前后镜头
- 浏览器拒绝权限后，需要用户自行在浏览器设置中重新允许
- iPhone / Safari 的录制格式和下载行为尚需针对不同 iOS 版本持续测试
- 不同设备、光线和摄像头角度会影响 MediaPipe 手势体验
- 旧款 iPhone 可能无法完成浏览器内 MP4 转换，但会保留原始 WebM
- 低端移动设备可能自动降低泡泡数量、布料迭代或裂缝视觉细节
